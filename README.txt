Meow Fortress - Android project (WebView app, 9:16 portrait)

Build the APK, pick one:
1. Android Studio: File > Open this folder, wait for Gradle sync, then Build > Build APK(s).
2. No install: push this folder to a GitHub repo, open Actions > Build APK, download "meow-fortress-apk".

Game: app/src/main/assets/index.html. Icons and splash: app/src/main/res.
